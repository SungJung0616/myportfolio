# Local editorial fonts

Bricolage Grotesque is used for the Hero name and secondary brand statement.
Manrope is used for Hero supporting text, actions and header navigation.
Both are Latin variable WOFF2 assets provided by Google Fonts, with the
corresponding SIL Open Font License notices included beside them.

Sources:
- https://github.com/google/fonts/tree/main/ofl/bricolagegrotesque
- https://github.com/google/fonts/tree/main/ofl/manrope

The WOFF2 files are the official Google Fonts Latin distributions, not locally
converted or AI-generated fonts. Combined font payload is approximately 102 KB.
No remote font request is required at runtime. Unsupported characters use the
CSS fallback font. The resume and 3D canvas-generated signage are unchanged.
