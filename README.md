# Sung Jung Portfolio

This repository powers my professional portfolio across operations systems, quality engineering, workflow automation, and independently delivered software projects.

The experience is designed as a basketball-inspired career scoreboard. Visitors can explore verified experience, strengths, project archives, and detailed case studies while keeping the clarity expected from a professional resume site.

```bash
npm install

```

Create a production build with:

```bash
npm run build
```

## Source-of-Truth Principle

Career facts are maintained in CareerOS and reused across the resume, portfolio, interview preparation, and professional profiles. Metrics are included only when their basis is defensible. Employer code, internal data, credentials, and confidential client information are not published.
